# Blender TA Tools

这是我在大一期间，通过 Python + Blender API 独立开发的自动化工具集。

## 工具列表

1\. \*\*批量归零重置\*\*：一键将选中网格物体的轴心归零并重置缩放，支持Ctrl+Z撤销。

2\. \*\*批量导出FBX\*\*：一键将选中物体导出到桌面指定文件夹中，支持自定义路径。

## 安装方法

在 Blender 中点击【编辑】->【偏好设置】->【插件】->【安装】，选择对应的 `.py` 文件即可启用。
